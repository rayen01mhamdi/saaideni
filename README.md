# 🚨 SILENT SIGNAL (ساعِدني)
### When words fail, help speaks.

**SILENT SIGNAL** is an innovative, lightweight, 100% offline emergency companion and survival assistant designed for travelers, international students, tourists, and anyone who may find themselves in an unfamiliar or dangerous situation where verbal communication is impossible.

---

## 🌟 Core Innovations & Features

### 1. 🖼️ Silent Signal Board (Visual Pictogram Communication)
- **Visual Symbols**: Pictograms grouped into intuitive categories (*Medical, Safety, Communication, Travel, Personal Needs*).
- **Message Composer**: Combines selected pictograms into natural, grammatically correct sentences in the target local language.
- **Multi-Language Support**: Fully supports English, French, Arabic (with RTL layout), Spanish, German, Italian, Turkish, Japanese, Chinese, and Russian.
- **Full-Screen Display & TTS**: Instantly displays messages in large, high-contrast text and reads them out loud using offline Android Text-to-Speech (TTS).

### 2. 🆘 Panic Mode
- High-stress emergency interface accessible instantly from the home dashboard.
- Displays real-time GPS coordinates, accuracy, and timestamp.
- Bundled official country emergency numbers (*Police, Ambulance, Fire*) with direct dial intent actions.

### 3. 🔋 Last 5% Mode (Battery Saver Emergency Mode)
- Ultra low-power true-black OLED theme (`#000000`) with zero unnecessary animations.
- Immediate display of GPS location, saved hotel/accommodation address, primary emergency contact, and local emergency numbers.

### 4. 🌍 Auto-Detect Country & Nearest Emergency Finder
- **Offline Reverse Geocoding**: Automatically detects the country from GPS coordinates without internet connection.
- **Nearest Facilities Finder**: Uses the Haversine spatial formula to calculate and display the **Nearest Hospital** and **Nearest Police Station** with real-time distance estimation (`~1.2 km`) and one-tap calling.

### 5. 🪪 My Travel Card & Flip Presentation Mode
- Secure local storage for personal info, nationality, emergency contacts, hotel address, blood type, and medical notes.
- **Profile Photo Support**: Pick an ID or profile photo from local storage.
- **Full-Screen Flip Presentation Card**: Turns the emergency card into a landscape presentation mode to easily show doctors, paramedics, or police officers.

### 6. 🧭 Lost Abroad Assistant & Survival Guide
- **Decision Tree Wizard**: Step-by-step offline guidance for common traveler emergencies (*Lost passport, lost phone, lost in city, hospital needed*).
- **Survival Guide Cards**: Concise guidance on medical emergencies, fire evacuation, road accidents, and theft.

---

## 🔒 Privacy & Security Guarantee
- **100% Offline**: No internet permission requested or required.
- **Zero Tracking**: No backend, no servers, no analytics, no advertisements, no subscriptions, and no cloud AI.
- **Local Storage Only**: All personal data and travel card details remain strictly on your device.

---

## 🛠️ Tech Stack
- **Language**: 100% Kotlin
- **UI Toolkit**: Jetpack Compose & Material 3
- **Architecture**: MVVM (Model-View-ViewModel) with Kotlin Coroutines & StateFlow
- **Local Storage**: Jetpack DataStore Preferences
- **Location & TTS**: Android System LocationManager & TextToSpeech APIs

## 📦 Getting Started & Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/rayen01mhamdi/saaideni.git
   ```
2. Open the project in **Android Studio** (Koala / Jellyfish / Ladybug or newer).
3. Sync Gradle and run the app on an Android emulator or physical device.
